# 요원 큐브: 직육면체와 정육면체

5학년 수학 5단원 2차시 「직육면체와 정육면체를 알아볼까요」 수업용 웹 자료입니다.

- `tv.html` — TV(교사)용. 오른쪽 위 '교사 메뉴'로 장면을 바로 이동할 수 있습니다.
- `student.html` — 학생 패드용. TV에 나온 암호로 미션을 엽니다. 마지막에 요원 기록을 PDF로 저장합니다.
- `index.html` — 두 화면으로 가는 첫 화면.

미션 4(도형다나와)에는 직육면체·정육면체 모형을 나란히 놓고 돌려 보며 면·모서리·꼭짓점을 세고, 모서리 길이를 색으로 비교하는 '모형 비교대'가 있습니다.
